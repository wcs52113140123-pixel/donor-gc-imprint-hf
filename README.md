# Donor-heart glucocorticoid-like imprint in human heart failure transcriptomics

Code, frozen analysis plans, gene sets, result tables and a correction tool for:
**"A Glucocorticoid-Like Imprint in Donor Control Hearts Can Confound Heart Failure Transcriptomics"** (manuscript submitted to JACC: Basic to Translational Science).

## Contents

| `02_code/` | `pbtools_v11.py` (shared pseudobulk/model utilities); `v1.2/` in vitro GC reference (`steroid_reference.R`), tests G1 and G2–G5; `v1.3/` tests C, K, A, post hoc identifiability and revision analyses, de-duplicated substate rerun; `figures/` figure script; `reproducibility/` make-based pipeline (`Makefile`, `run_all.sh`, `repro_bundle.tgz` with wrapped upstream scripts). |

## Data (all public; not redistributed here)
GSE290367 (GEO), SCP3342 (Single Cell Portal), Hahn et al. 2021 RV septal bulk RNA-seq (supplementary files of the original publication), GSE141910 (MAGNet), GTEx v11 (heart left ventricle, atrial appendage; sample attributes via dbGaP-open files), and in vitro datasets GSE85333, GSE112101, E-MEXP-2598, E-MTAB-7572 (plus GSE150049 and GSE35683, which failed QC). Accessions and sample selection are listed in Supplemental Table S2.

## Running
- Python 3.10+ with numpy, pandas, scipy, statsmodels, scanpy 1.11.5, anndata 0.11.4, harmonypy 2.0.2; R 4.x with limma, edgeR, data.table, readxl.
- Scripts were run on a Linux server with the project root hard-coded (`ROOT`/`PROJ_ROOT` near the top of each script). Set it to your local copy of the raw/processed data before running. Paths were left as run so that the code matches the hashed outputs.
- `02_code/reproducibility/run_all.sh` reruns the analyses in dependency order (29 targets). In a full rerun of 140 output files, 92 were byte-identical and 17 numerically identical (|Δ| < 1e-6) to the archived versions, 14 differed only in rendering, and 11 were not regenerated by the pipeline (see Supplemental Section S-R6 of the article); SCP3342 label transfer reproduces exactly only with harmonypy 2.0.2.

## Using the GC tools
```python
from gc_tools import gc_flag, gc_score, gc_collinearity, gc_adjusted_de
flagged = gc_flag(de_table, gene_col="gene")          # add GC class to any DE list
s = gc_score(Z, genes, ref_mask)                      # 3-gene GC score (FKBP5, TSC22D3, ZBTB16)
gc_collinearity(design, s)                            # check identifiability before adjusting
res = gc_adjusted_de(Z, genes, design, s)             # warns if the score is aliased with diagnosis
```
The identifiability thresholds (AUC >= 0.9 or <= 0.1, or variance inflation >= 5) are a post hoc recommendation, not a validated rule.
